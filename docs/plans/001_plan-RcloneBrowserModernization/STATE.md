## 10. Do-not-repeat

- R14: bisync with long absolute paths exceeds the 255-byte lock or listing file name limit (`Lock file exists, but contents are unreadable`). Tests use short relative paths.
- R16: `rclone serve s3 --auth-key AK,SK` gave `InvalidAccessKeyId` with a matching remote. Tests use anonymous `serve s3`.
- R12: `operations/list` with `fs = "loc:"` plus an absolute `remote` gives `directory not found`. Use `fs = "<remote>:<path>"` and `remote = ""`.
- R13: answering rc config questions only through `opt.result` stores passwords in clear text. Always echo the answers in `parameters`.
- R1: never pass `--log-level` together with `-v`, and never trust the host `RCLONE_*` logging env (the host has `RCLONE_VERBOSE=1`, `RCLONE_STATS=5s`, `RCLONE_STATS_ONE_LINE=true`).
- U6: no `gh`, `curl`, `git fetch`, `docker pull`, `scripts/dev.sh image` or `apt` inside containers.
- Commit trailers: the PEV trailers and `Co-Authored-By` must form one final paragraph (no blank line between them), or git sees only the last paragraph as trailers (0.1 was amended for this before advancing).
- R17: never treat a `{}` reply of rc `config/unlock` as proof of the right password; verify with a config-using call (`config/listremotes`).
- R10: rc parameters given as `rclone rc cmd k=v` are JSON strings; send `vfs/refresh {"recursive":"true"}`, never a JSON boolean, and copy a CLI probe into a JSON body only with that typing.
- R18: never echo every rc config answer in `parameters` (it pins every default into rclone.conf), never answer an Update password with `""` (it overwrites it with an obscured empty string), and never answer `config_fs_advanced` with `true` under `all:true` (the flow never ends).
- STATE writes before git: chain the git command after the STATE edit script with `&&`, never `;`. In 4.1 an assert failed in the STATE script and the cherry-pick ran anyway, so the checkpoint had to be rewritten.
- B-T1: an obscured rclone value is base64url and may start with `-`. Pass it after `--` (`rclone reveal --config <tmp> -- <value>`), never as a bare argument, and keep `--config` before a `--`.
- 7.1: `MainWindow`'s constructor reads `Settings/rclone`; a test that constructs it must set that key (e.g. `/bin/false`), or the constructor searches PATH and blocks in a modal box until the ctest timeout.
- B-T2: a `QProcess` child of a window must not reach the window after its members are gone: disconnect the children in the destructor (`~QProcess` kills a running process and emits `finished()`).
