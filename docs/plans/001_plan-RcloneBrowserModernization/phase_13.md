## Local design context
Plan revision: 1.
- D15: translations come from `qt_add_translations` with `translations/rclone-browser_it.ts`. The language setting is `Settings/language` (`system`/`en`/`it`), applied after a restart.
- R6: LinguistTools is absent from the plan-time image. P-5 rebuilds it from the 0.1 Dockerfile. CMake uses `find_package(Qt6 … OPTIONAL_COMPONENTS LinguistTools)`. A new CMake option, `RB_REQUIRE_TRANSLATIONS` (default OFF), turns it into a hard requirement. `scripts/dev.sh build` passes `-DRB_REQUIRE_TRANSLATIONS=ON` from 12.1 on, and the CI Linux job passes it too.
- English stays unchanged: with no translator installed, `tr()` returns the source text. So T-MW-SNAPSHOT (7.1) must stay byte-identical through 12.1 and 12.2. That is the behavior oracle for the wrapping work.
- Wrapping rules (12.2), as an exhaustive policy:
  - Wrap every user-visible literal shown in widgets, message boxes, tooltips, status tips, menus, dialogs and notifications. In QObject subclasses use `tr("…")`. Elsewhere use `QCoreApplication::translate("<ClassOrFile>", "…")`.
  - Use `%1` placeholders instead of concatenating translated fragments with values. Keep the accelerators (`&`).
  - Never wrap (deny list):
    - settings keys (`Settings/…`, group names);
    - rclone commands and flags (anything starting with `-`, `copy`, `lsjson`, …);
    - rc paths and JSON keys;
    - file names and extensions; URLs; regex patterns; objectNames;
    - job status identifiers (`"finished"`, `"error"`, `"stopped"`, `"1_transfer_finished"`, `"2_transfer_error"`, `"2_transfer_stopped"`, `"0_zmount_mounted"`, and every other `mStatus` value);
    - any literal that is compared (`==`, `compare`, `contains`, `startsWith`, `indexOf`) or used as a map key;
    - the transfer-mode strings returned by `TransferDialog::getMode()` if they are compared anywhere. If they are only displayed, wrap them at the display site, not at the source.
  - `.ui` strings are already translatable through `retranslateUi` and need no change.
